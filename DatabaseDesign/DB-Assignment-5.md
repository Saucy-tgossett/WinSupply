# Assignment 5 SQL Business Queries
## SQL Query
- A query means a request for a data from a database. It allows you to request data from multiple data tables.

## Select Statements
- `SELECT`: Chooses which columns to show.
- `FROM`: Names the table the data comes from.
- `WHERE`: Filter the rows so only the ons that meet a condition are shown.
- `GROUP BY`: Groups rows with the same value so functions like `COUNT` or `AVG` give one result per group.
- `ORDER BY`: Sorts the results, ascending `(ASC)` or descending `(DESC)`.

# Filtering a Query
- You can filter a query with the `WHERE` clause, which typically goes after the `FROM`. But it has to match specific `id` using the `=` equality operator. 

# Database Indexes
- An index is a separate data structure that maintains pointers to the actual table rows, sorted by the indexed column values. Database indexes benefit you by giving you faster searches, and faster joins, faster sorting and groupings.
